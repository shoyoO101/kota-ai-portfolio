# Kota AI Portfolio

Build a minimal, premium dark-mode portfolio landing page for Kota AI (founded by Kareem, an AI Systems Architect). 

Aesthetic & Design Guidelines:

- Anti-AI Template Style: No glowing 3D blobs or generic corporate agency copy.

- Visual Style: Sleek, high-craft developer aesthetic inspired by Linear.app and Vercel. Dark neutral background (#0D0D10), subtle slate-gray borders (#1E1E24), crisp monochrome typography, and refined muted indigo accents.

- Layout: Clean single-column container with generous padding, sharp borders, and glassmorphism cards.

Page Structure:

1. Minimal Header:

- Left: "Kota AI" text badge with a small status indicator ("🟢 Open for Async Projects").

- Right: Navigation links ("Work", "Capabilities", "Tech Stack") and a minimalist border button "Request Audit".

2. Hero Section:

- Eyebrow pill: "AI Systems Architect & Automation Specialist"

- Main Headline: "I build autonomous workflows and custom AI systems that run quietly in the background."

- Subheadline: "Send me your manual bottleneck, and I'll send back a custom video breakdown showing how to automate it."

- Action Buttons: Primary button "Request a Free Video Audit" and secondary link "See Sample Workflows".

- Visual Mockup: A clean code/workflow preview card showing an active pipeline (e.g., Webhook Trigger -> LLM Parsing -> Vector DB Search -> Action).

3. Featured Work / Automation Showcase (3 Project Cards):

- Project 1: "Multi-Platform Customer Support Agent" – Autonomous web chat & messaging automation connected to internal knowledge bases.

- Project 2: "Lead Intake & CRM Pipeline" – Automated lead qualification, instant scoring, and routing via custom webhooks.

- Project 3: "RAG & Vector Knowledge Systems" – Context-aware search tools built for instant data retrieval across documents.

4. Core Capabilities (Grid Layout):

- Custom AI Agents (Autonomous decision-making, API execution)

- Workflow Engineering (n8n, webhooks, complex backend pipelines)

- Embedded Chat Widgets (Lightweight, zero-lag UI widgets)

- Database & Vector Integrations (Qdrant, custom knowledge bases)

5. Tech Stack & Tools (Clean Badge Cloud):

- Badges for: n8n, Python, OpenAI, Anthropic, Qdrant, Webhooks, Postman, REST APIs, WhatsApp Business API.

6. Async Request Section:

- Card Headline: "Get a free 5-minute Loom audit of your process."

- Subheadline: "Describe the repetitive work holding your business back. I'll record a personalized video walking through the exact automation architecture to fix it."

- Short Form: Name, Email, "What manual task do you want to eliminate?", and a solid submit button "Get My Video Audit".

7. Minimal Footer:

- "Designed by Kota AI © 2026. Built for precision."
